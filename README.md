RESUMETER: A Resume Analyzer

This is a simple, privacy-focused Resume Analyzer tool built as part of our 4th semester live project.
It helps students understand how ATS (Applicant Tracking Systems) works and provides actionable suggestions to improve their resumes.

Tech Stack:
- Frontend: React
- Backend: Node.js + Express
- Logic Layer: Python (for rule-based resume analysis)

Features:
- No database — resumes are not stored.
- No sign-up required — just upload and get the analysis.
- Minimal, student-friendly design.

How It Works:
1. User uploads resume (PDF or DOCX).
2. Backend sends it to the Python logic layer.
3. Results are analyzed and displayed.
